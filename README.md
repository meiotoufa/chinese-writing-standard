# 中文写作标准

一个用于中文写作、修改和润色的 Agent Skill。让表达准确、通顺、具体、连贯、简练，符合现代汉语习惯。

适用于中文文档、工作报告、答辩材料、技术说明和日常沟通。完整规则见 [SKILL.md](SKILL.md)。

## 核心原则

- 保留原意、事实、立场、数据和不确定性，不因润色加强结论。
- 让主语、指代、条件和逻辑关系清楚。
- 优先说明具体动作、对象和结果，减少抽象名词、套话和重复。
- 按读者与场合选择语气、结构和详略，不机械追求短句。
- 规则冲突时，优先保证原意与事实准确，其次保证理解顺畅，再考虑简练和形式。

## 使用前后对比

以下是为展示写作差异而编写的示例：每组先生成一版未套用本标准的初稿，再按标准改写。它们不是独立模型实验，也不代表所有未使用该 Skill 的输出都会出现这些问题。示例中的数据均为虚构情境，不是实际实验结果。

### 例一：工作汇报

**同一任务：** 写一段项目进展。已完成登录接口联调；支付接口尚未完成，因为测试账号没有开通权限；下一步联系支付平台开通权限，随后继续联调。不要添加时间承诺。

**未套用标准的初稿：**

> 目前，项目整体联调工作正在持续推进中，登录接口方面已完成相关联调工作，支付接口方面由于测试账号权限尚未开通，相关工作暂时还未完成。后续将积极加强与支付平台的沟通协调，推动权限开通，并在此基础上进一步开展支付接口的联调工作。

**按标准改写：**

> 登录接口已完成联调。支付接口尚未完成联调，原因是测试账号还没有开通权限。下一步联系支付平台开通权限，随后继续联调支付接口。

**改在哪里：** 删除“持续推进”“积极加强”“在此基础上”等冗余表达，直接交代完成项、阻碍和下一步；没有添加完成日期。

### 例二：论文表述

**同一任务：** 写一段实验结果说明。在数据集 A 上，方法 B 的准确率为 82%，基线 C 为 79%。目前只测了一个数据集，不能推断其他场景表现。

**未套用标准的初稿：**

> 从实验结果来看，方法 B 在数据集 A 上实现了准确率方面的提升，其准确率达到了 82%，而基线 C 的准确率为 79%，这表明方法 B 在当前实验条件下具有一定的性能优势。不过，鉴于目前的实验仅在一个数据集上开展，对于其他场景下的表现，仍然需要通过进一步的实验进行验证。

**按标准改写：**

> 在数据集 A 上，方法 B 的准确率为 82%，比基线 C 的 79% 高 3 个百分点。目前仅测试了一个数据集，其他场景下的表现仍需验证。

**改在哪里：** 用具体指标说明差异，将“准确率方面的提升”改为可核对的比较；区分百分点与百分比，并保留实验范围的限制。

### 例三：日常沟通

**同一任务：** 请同事在今天下午 3 点前核对表格里的预算数字，有问题就在表格中标注，自己收到后统一修改。语气自然、礼貌。

**未套用标准的初稿：**

> 为了更好地推进后续工作，想麻烦你在今天下午 3 点之前对表格中的预算数字进行一下核对。如在核对过程中发现存在问题的地方，也请在表格中进行相应标注，我会在收到反馈后统一进行修改。感谢你的支持与配合！

**按标准改写：**

> 麻烦你今天下午 3 点前核对一下表格里的预算数字，有问题直接在表格中标注。我收到后会统一修改，谢谢！

**改在哪里：** 保留请求、截止时间、反馈方式和后续动作，删去无具体信息的开场和重复的“进行”，保留礼貌语气。

## 安装

### Codex 本地安装

将仓库克隆到个人技能目录；如果目标目录已有同名技能，先检查内容，避免覆盖。

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/meiotoufa/chinese-writing-standard.git ~/.agents/skills/chinese-writing-standard
```

Codex 的本地技能目录和调用方式见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。如果新技能没有出现，重启 Codex。

### 其他支持 SKILL.md 的工具

下载仓库，把整个 `chinese-writing-standard` 文件夹放到工具指定的技能目录。具体安装路径与调用方式以该工具的文档为准。

## 使用

在 Codex CLI 或 IDE 扩展中，可以在提示词里提及 `$chinese-writing-standard`：

```text
请使用 $chinese-writing-standard 润色下面这段中文。
保留原意、事实、数据和结论限制，不补充未经证实的信息。

【粘贴原文】
```

也可以用于从头撰写：

```text
请使用 $chinese-writing-standard 写一段项目进展说明。
读者是项目组同事，语气自然、清楚。
已知事实：登录接口已完成联调；支付接口因测试账号权限尚未开通而未完成。
下一步：联系支付平台开通权限，再继续联调。
不要添加时间承诺。
```
